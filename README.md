
# Python Quiz Game

## Project Overview
The Python Quiz Game is a simple interactive quiz application developed using Python.

It displays multiple-choice questions, accepts user answers, checks the answers, calculates the score, and displays the final result.

## Features
- User name input
- Multiple-choice questions
- Automatic answer checking
- Score calculation
- Final result display
- Input validation

## Technologies Used
- Python
- VS Code
- Python Standard Library

## Project Structure
- main.py
- questions.py
- requirements.txt
- .gitignore

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

python main.py
